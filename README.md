# excel-expense-tracker-mini-project
A beginner-friendly Excel mini project to track personal expenses, analyze spending patterns, and build basic dashboards using Excel formulas and pivot tables.
## Excel Expense Tracker Project

### Tools Used
- Microsoft Excel
- Pivot Tables
- Charts

### Key Features
- Category-wise expense analysis
- Payment mode usage analysis
- Monthly expense dashboard

### Insights
- Identified most used payment mode
- Found highest spending category
